## One-click latest-source refresh (cross-cutting requirement)

From the existing thesis, meeting preparation or one-pager in Charlie, the investor
should give one instruction to refresh selected outputs from recent available
sources. Build on existing managed collection and assignment orchestration:

- Freeze ticker/company identity, event window, source preferences, selected outputs,
  destination, instructions and the baseline/version being updated at submission.
- Search signed-in AlphaSense for relevant eligible broker reports, event/earnings
  transcripts, releases and presentations; support earnings filings through the
  verified public-filings path rather than relabeling unsupported source types.
- Screen for relevance, contrary evidence, duplicates and usage restrictions.
  Preserve source policies and the existing bounded pack; do not silently widen it.
- Preserve original bytes in the selected iCloud folder and verify exact-byte
  cloud import receipts before describing sources as available in Charlie.
- Use one frozen source pack to prepare the selected updated deliverables. Reuse
  safe completed stages and never dispatch duplicate paid research on uncertain
  network/provider outcomes. Preserve prior outputs and source provenance.
- Show collection, import, analysis, generation and review states in Activity and
  the originating workspace, including honest missing-coverage explanations.
- Prepare thesis changes as reviewable proposals; never silently overwrite the
  accepted thesis or approve notes/recaps. Preserve existing review/version rules.
- Historical filings/current market data may supplement financial charts and
  valuation as the user previously authorized; the event window still governs
  recent-event coverage. Display vintages and distinguish historical data from news.

Mac awake/online, running agent, Codex/browser access, signed-in AlphaSense and
network availability remain explicit dependencies. One click means one coordinated
instruction, not a promise of instantaneous browser collection or source availability.
